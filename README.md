### How does It work?
The tool starts up and download the tool immediately from https://github.com/Classity-Real/Files/releases/download/Tools/Internal.zip 
then extracts it to the app files. It requests root because the commands request for it, once its granted it will start working as usual.
### What features does it have?
It has standard features like:
 - Files
 - Backup
 - Flashing
 - Tools
 - Device Configurations: **It detects if the user creates a folder on the chipset folder, making it as a manufacturer folder.**

These are final, If any features I didn't list. Let me know
